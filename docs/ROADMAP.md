# Roadmap

## Near term

- [ ] Add an approved Standard Ebooks catalogue feed when public project access is available
- [ ] Add a persistent, privacy-preserving metadata index so slow upstreams do not sit on the search request path
- [ ] Resolve ISBN and Open Library work identifiers before exact title-and-author fallback clustering
- [ ] Add Welsh-language interface copy and language-aware catalogue selection
- [ ] Make saved works exportable as OPDS or JSON without an account
- [ ] Complete OpenAI app verification and submit the public MCP integration for review

## Research

- Work-level availability graphs that distinguish the abstract work, editions and access offers
- Source health scoring and stale catalogue snapshots for degraded upstreams
- Evaluate Reciprocal Rank Fusion against a maintained relevance judgement set and publish the measurements
- Jurisdiction data that cites authoritative rules without presenting automated legal conclusions

## Ongoing

- Accessibility and keyboard navigation
- Mobile performance
- Clearer rights, edition and provenance labels
- Additional documented lawful catalogues
- Parser fixtures and live contract monitoring

Roadmap items are not promises. Open an issue before starting substantial work.
