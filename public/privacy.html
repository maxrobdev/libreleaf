LibreLeaf

Privacy

Last updated: 16 August 2026.

LibreLeaf does not require an account and does not ask for personal data. Its website and read-only MCP server send book search terms to Project Gutenberg and Open Library to return catalogue results.

Hosting providers may process standard request metadata such as IP address, user agent, requested URL, and timestamps for security and service operation. LibreLeaf does not sell personal data or use book searches for advertising profiles.

Third-party sources

Opening a result sends you to Project Gutenberg or Open Library, whose own privacy terms apply. LibreLeaf returns only public catalogue metadata and source links.

Contact

For privacy questions, use the public support details on the About page or open an issue in the LibreLeaf repository.
