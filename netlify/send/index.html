LibreSend

This lightweight page remains readable when an older Kindle or Kobo browser cannot run the full interface.

Kindle

  1. On a phone, share the EPUB or PDF to the Kindle app.
  2. On a computer, open Amazon Send to Kindle, select the file and sync the Kindle.
  3. For email delivery, use the approved address and device email in Amazon's personal-document settings.

Kobo or another device on this Wi-Fi

Run the first-party LibreSend Local app on the computer, choose one book in its localhost page, then open the private address it displays on the receiving device.
